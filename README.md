# 折叠屏模拟（FoldingScreenApp）

Android 原生应用（Kotlin），实现「空间锚定显示」与「万向折叠屏模拟」两大模式。应用无主界面：启动即透明 Activity 自动申请权限，权限通过后启动前台服务并自毁，桌面仅保留一个悬浮控制按钮。

## 功能特性

- **无主界面**：启动即透明 Activity → 自动申请悬浮窗权限 → 启动前台服务 → 自毁，桌面仅保留悬浮控制按钮
- **悬浮控制按钮**：半透明白色圆形（直径 48dp，透明度 50%），可自由拖拽、松手自动吸附左右边缘；文字随模式与状态变化
- **模式一 · 空间锚定显示**：屏幕内容锚定在真实物理空间保持固定朝向；旋转手机时画面做反向补偿变换（逆三维旋转变换），手机如同观察窗口，空余区域填充纯黑。仅响应旋转姿态，不处理位移、不改变纹理缩放、无 3D 透视变形
- **模式二 · 万向折叠屏模拟**：模拟折叠屏物理弯曲动画。折叠轴可在屏幕平面内 0~360° 任意旋转朝向；折叠角 0~180° 连续可调；画面沿折叠轴呈平滑圆柱曲面弯曲，折痕处有动态高光与内侧阴影，模拟玻璃折叠质感；弯曲后保持正交投影，内容比例不失真
- **技术栈**：MediaProjection 实时采集 → OpenGL ES 2.0（EGL window surface + 60fps vsync）→ 32×32 顶点网格圆柱弯曲 → 指数平滑动画
- **后台保活**：前台服务（`mediaProjection` 类型）常驻通知栏
- **资源管理**：模式关闭/退出时按创建逆序释放渲染线程 / 悬浮层 / 虚拟显示 / 传感器 / MediaProjection，无内存泄漏

## 项目结构

```
app/src/main/java/com/example/foldingscreen/
├── LaunchActivity.kt               # 透明启动 Activity（权限申请 → 启动服务 → 自毁）
├── MediaProjectionRequestActivity.kt # 录屏授权对话框宿主（动态申请）
├── OverlayService.kt               # 前台服务：悬浮窗管理、双模式状态机、全生命周期
├── FloatingButtonView.kt           # 悬浮按钮（拖拽/吸附/单击/双击/长按/滑动调参）

├── ScreenCapturer.kt               # MediaProjection + VirtualDisplay + ImageReader
├── FoldMath.kt                     # 万向折叠数学：折叠轴、圆柱变换、光影参数

```

## 核心变换原理

### 空间锚定

```
基准姿态 R0 ──┐
              ├─→ 相对旋转 R_rel = R1ᵀ·R0（开启瞬间 → 当前）
当前姿态 R1 ──┘
              │
全屏四边形(z=0) × 模型矩阵 R_rel → 正交投影（无透视）→ 空余区域 glClear 纯黑
```

### 万向折叠

```
折叠轴 a=(cosθ, sinθ)，法向 n=(-sinθ, cosθ)，折叠角 φ（0~180°）
顶点到轴距离 d = dot(p, n)，圆柱半径 r = 2L/φ（L = 半对角线）
新坐标：p' = a·t + n·r·sin(d/r) + z·r·(1-cos(d/r))   ← 弧长不变 → 内容不失真
光影：折痕高光 = k₁·(φ/π)·exp(-d²/2σ²)，内侧阴影 = k₂·(φ/π)·(1-cos(d/r))
```

## 使用说明

1. 安装 APK 后点击图标启动：应用自动申请「悬浮窗」权限 → 跳转系统设置开启 → 返回后前台服务启动，桌面出现悬浮按钮，应用自动退出（无主界面）。
2. 首次开启模式时系统会弹出「开始录制或投屏」授权框，请选择**允许**（并建议勾选"始终允许"）；授权成功后投影会话在本服务生命周期内常驻，后续开关模式无需重复授权。
3. 退出：点击通知栏常驻通知的「停止」按钮。

### 悬浮按钮操作指引

| 手势 | 功能 |
|---|---|
| **短按** | 切换当前模式 开启/关闭（按钮显示模式名 ↔ 「停止」） |
| **长按** | 弹出模式菜单，切换「空间锚定模式 / 万向折叠模式」 |
| **双击** | 折叠模式：快速复位折叠角度到 0°（带动画过渡） |
| **上滑 / 下滑** | 折叠模式开启时：增大 / 减小折叠角度（0~180°） |
| **左滑 / 右滑** | 折叠模式开启时：逆时针 / 顺时针旋转折叠轴朝向（0~360°） |
| **慢速拖拽** | 移动按钮位置，松手自动吸附屏幕左右边缘 |

> 说明：折叠模式开启时，**快速滑动**用于调参（按钮不动），**慢速拖拽**用于移动按钮，两者可同时使用。

### 模式一 · 空间锚定操作指引

1. 长按按钮 → 选择「空间锚定模式」；
2. 短按开启。开启瞬间记录当前手机朝向为**基准姿态**，画面即被锚定在该物理朝向；
3. 旋转手机：画面反向补偿，始终固定在基准方向，转动仅改变可视区域，空余区域纯黑；
4. 再次短按关闭。重新开启会重新记录基准姿态并刷新画面快照。

### 模式二 · 万向折叠操作指引

1. 长按按钮 → 选择「万向折叠模式」；
2. 短按开启，画面以当前屏幕为源；
3. 上滑/下滑调整折叠角度：0° 完全展开（正常全屏）→ 180° 完全对折，中间任意角度平滑弯曲；
4. 左滑/右滑旋转折叠轴：折痕可在屏幕平面内 360° 任意朝向（水平、垂直、斜向皆可）；
5. 双击快速复位到 0° 展开，带动画过渡。

## 已知限制

1. **画面源为「开启瞬间的实时快照」**：Android 的 MediaProjection 会把本应用的全屏悬浮渲染层一并采入画面（FLAG_SECURE 又会使被覆盖区域在采集中整块变黑），因此渲染层显示期间无法再从系统获得纯净实时帧。应用在开启瞬间先采一帧纯净画面再上渲染层——折叠/锚定**变换本身为实时 60fps**，仅纹理为快照；每次重新开启都会刷新快照。如需折叠"实时"内容，可先开启折叠模式再操作其他应用（快照会定格操作前的画面），或关闭再开启刷新。
2. **空间锚定仅响应旋转姿态**：不响应位移、不做纹理缩放，无 3D 透视（规格约束）。
3. **悬浮窗授权依赖系统设置页**：极少数 ROM 可能无标准悬浮窗设置入口，需在应用管理里手动开启「显示在其他应用上层」。
4. **录屏授权为单次 token**（Android 14 起）：若系统撤销了录屏授权（如从状态栏停止），重新开启模式时会再次弹出授权框。
5. **姿态传感器**：个别设备首次启用时传感器校准需 1~2 秒，期间可能有轻微漂移；不支持旋转矢量传感器的设备空间锚定模式不可用（折叠模式不受影响）。
6. **折叠效果**：折叠弯曲为圆柱面数学模型（半径 = 2L/φ），180° 时呈半圆柱形对折；折痕高光与阴影为顶点光照插值，参数可在 `FoldMath` 中调节。
