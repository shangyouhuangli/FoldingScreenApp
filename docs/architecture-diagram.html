折叠屏模拟 · 应用架构与双模式渲染管线
示意结构：基于本工程源码（com.example.foldingscreen），非官方架构图
① 启动流程（无主界面）
点击图标 → LaunchActivity（透明） → 悬浮窗权限 + 通知权限 → OverlayService 前台服务（mediaProjection 类型） → 桌面仅剩 48dp 悬浮按钮 · Activity 自毁
② 双模式渲染管线（同一 GL 线程 / 同一屏幕纹理 / 60fps vsync）
模式一 · 空间锚定显示
TYPE_ROTATION_VECTOR（SENSOR_DELAY_GAME）
基准 R0 · 当前 R1 → 相对旋转 R_rel = R1ᵀ·R0
→ 全屏四边形(z=0) × R_rel（逆三维旋转变换）
→ 正交投影（无透视）→ 空余区域纯黑填充
约束：仅响应旋转，不处理位移 / 不改变纹理缩放 / 无 3D 透视
模式二 · 万向折叠屏模拟
折叠轴 a=(cosθ,sinθ) 0~360° · 折叠角 φ 0~180°
→ 32×32 顶点网格，圆柱半径 r = 2L/φ
→ p' = a·t + n·r·sinα + z·r·(1−cosα)，α=d/r（弧长不变）
→ 折痕高光 exp(−d²/2σ²) + 内侧阴影 (1−cosα) × 顶点光照
约束：内容比例不变形 / 正交投影无近大远小 / 指数平滑动画无跳变
③ 悬浮按钮手势 → 控制映射（折叠模式开启时）
短按 → 模式开/关 长按 → 模式菜单 上/下滑 → 折叠角 ±（0~180°） 左/右滑 → 折叠轴 0~360° 双击 → 复位展开（动画） 慢速拖拽 → 移动 + 边缘吸附
④ 模式关闭 / 退出时按创建逆序释放
GL 渲染线程/EGL → 悬浮渲染层 → 虚拟显示/ImageReader → 姿态传感器 → MediaProjection → 悬浮按钮
画面源说明：MediaProjection 会采集悬浮层自身，故渲染层出现前先采一帧纯净画面作为纹理，变换为实时 60fps，纹理为开启瞬间快照（详见 README 已知限制）。
